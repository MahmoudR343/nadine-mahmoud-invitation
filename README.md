# Nadine & Mahmoud – Wedding Invitation (third design)

Live invitation: https://mahmoudr343.github.io/nadine-mahmoud-invitation/

Built on Nadine & Mahmoud's own seven page designs, in English and Arabic.

## Updating the details

The date, start time, venue and Google Maps link live in **`config.js`**.

1. Open `config.js` here and click the pencil icon (Edit).
2. Change only the text between the quotation marks, e.g. `time: "19:00"`.
3. Click **Commit changes**. The site updates within a minute or two.

## Notes

- The countdown runs to midnight on 17 July 2027, Istanbul time, unless `time` is filled in.
- The RSVP form is a design preview only: it does not send or save replies.
- Music: `assets/music.mp3` (soft piano piece "Ivory Lullaby"). Replace that file with another MP3 of the same name to change it, or set `playMusicOnOpen: false` in `config.js` so it only plays from the music button.
